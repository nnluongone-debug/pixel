# Cosmetic collectibles: brick skins + arcade sound packs

Goal: players collect new looks for their pixel tower and new arcade sound
sets, unlocked by level (and later by a Pro purchase).

## Catalog (proposal — thresholds to confirm)

| Kind | Item | Unlock |
|---|---|---|
| Skin | Neon Glow (current look) | Default |
| Skin | Game Boy Classic — 4 moss-green shades, no glow, hard pixel edges | Level 3 |
| Skin | Cyberpunk Glitch — RGB split, scanlines, rare glitch jitter | Level 6 |
| Skin | Gemstones — faceted bricks, twinkling sparkles | Level 10 |
| Skin | Pure Gold Pixel — gold bevel, habit color as a small gem inlay | Level 15 or Pro |
| Sound | Neon Default (soft synth clicks) | Default |
| Sound | 8-Bit Platformer (original chiptune, Mario-*style*) | Level 2 |
| Sound | Space Arcade (original laser/zap set, Space Invaders-*style*) | Level 5 |
| Sound | Zen Wood (wood blocks, calm) | Level 8 |

Legal: no Nintendo/Taito audio, melodies or names. All SFX are synthesized
originals generated by a script in the repo (reproducible, license-clean).

## Key dependencies

- New package: `audioplayers` (AudioPool, low latency) — phase 3.
- Firestore rules: allow `cosmetics` map on `users/{uid}` — phase 1.
- Pro: Apple Developer Program ($99/yr) + Google Play Console ($25) +
  `in_app_purchase` + server receipt validation — phase 6.

## Decisions (owner, 2026-10-10)
